Personal Google API tools

This site describes OAuth apps that GitHub user WOULDU-pres uses only for personal work. They are not offered to the public.

  • gogcli (Google Cloud project "google cli"): a command-line client for the owner's own Google Drive, Gmail, Calendar, Sheets, Docs, Slides, Tasks and Forms.
  • Mini PM Drive: lets the owner's training-operations web app store and read files in the owner's own Google Drive.
