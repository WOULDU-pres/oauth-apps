Privacy policy

Applies to the OAuth apps "gogcli" and "Mini PM Drive" described on the home page. Last updated 2026-10-27.

Who uses these apps

Only the owner signs in to these apps, with the owner's own Google account. They are not offered to anyone else.

What data they access

With the owner's consent, the apps read and write the owner's Google Workspace data (such as Drive files, Gmail messages, calendar events and spreadsheets) to run commands the owner starts.

Storage and sharing

OAuth tokens are stored encrypted or with owner-only file permissions on the owner's own computer. Google user data is not sold, shared with third parties, used for advertising, or used to train AI models.

Limited Use

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
